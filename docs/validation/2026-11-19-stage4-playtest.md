## HUD 缺陷与修复

第一份素材在约 3 秒处能看到助手 HUD，15 秒和 40 秒处已没有。对照本机 Celeste 的实际实现，房间切换会卸载既非 Persistent 也非 Global 的实体，死亡复活时则卸载非 Global 实体。旧 HUD 没有 Global 标记；适配器又仅用场景引用判断是否需要重建，同一个 Level 对象中失去 HUD 后不会恢复。

修复：在构造 HUD 时设定 Global/HUD 等标记；记录 Removed/Added 生命周期，实体被移除后允许适配器重建；下移面板避开左上角计时器。补充起点、死亡、结束点和保存计数日志，便于对照路线清单。

使用本机游戏程序集单独执行实际 Level.UnloadLevel，并检查实际房间切换的实体过滤规则：旧版复现“复活后不存在、会被房间切换过滤”，修复后“复活后仍存在、不被房间切换过滤、Removed 标志正确”全部通过。此检查不启动游戏、不操作 OBS。全量 129 项测试通过，无跳过，构建 0 警告、0 错误。新版本仍需用户实际换房、死亡并按 Backspace 检查可见提示。
